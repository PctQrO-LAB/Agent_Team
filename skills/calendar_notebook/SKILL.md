# 笔记本日程技能

## 作用
- 在本地笔记本中保存/删除日程
- 查看日程仪表盘
- 执行受控 SQL 查询（仅诊断/只读场景）

## 依赖工具函数（AgentNotebook）
- save_schedule
- delete_schedule
- get_dashboard
- execute_sql_query (谨慎使用)

## 使用说明
1) 写入前提示用户要保存的时间、标题、参与人等关键信息。
2) 删除前先查询/确认，避免误删。
3) execute_sql_query 仅用于排查或导出，请明确查询目的并告知只读。

## 输出格式示例
- 保存："已记录日程：<标题> @ <时间>"
- 删除："已删除日程：<标题>"
- 仪表盘：简述任务数、今日/本周关键事项。

## 注意事项
- 不要执行非用户确认的写操作。
- 对时间字段保持 ISO8601，必要时写入时区。
