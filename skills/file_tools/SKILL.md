# 文件工具技能

通过封装好的 ID 方法，帮助智能体一键完成各类资产文件夹的初始化，并自动登记到数据库！你在系统中只与资产 ID 打交道，不必直接手写物理路径。

## 核心工具函数

### 1. `init_workspace(asset_id: str)`
**【绝对核心工具】** 这是一键初始化的黑盒中枢。
只要给出资产的标准ID即可，系统内部将：
- 自动分析层级。
- 自动生成符合物理规范的文件路径。
- 自动将其结构化注册进 SQLite 数据库，并设好兜底版本。

**你不需要再去写、去猜测绝对路径或相对路径，直接提供标准 ID。**

### 2. `read_image_as_url(local_path: str)`
读取本地图片，将其转化为云端或图床的链接给视觉代理用。

## 📌 全局唯一资产编号规范 (Global Unique Asset ID System)
在调用任何资产、场景、镜头相关的保存或读取工具时，必须遵循以下规则：
- 必须使用绝对编号作为名称（项目、场景、资产命名均如此），绝对禁止使用中文或自然语言拼音/单词。
- 格式规范：`pXX-scXX-类别XX`
- 项目(Project): `p01`
- 场景(Scene): `p01-sc01`
- 镜头(Shot): `p01-sc01-sh01`
- 角色(Character): `p01-ch01` (全局主角) 或 `p01-sc01-ch01` (场内辅助)
- 场景概念(Environment): `p01-sc01-en01`
- 道具(Prop): `p01-sc01-pr01`
